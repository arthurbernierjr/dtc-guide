**Read this with Session 9.2.** This lesson counts how many extra arrays an algorithm makes. Count their sizes too: an array's space is its element count times its element size, so one copy of a hundred-thousand-item array costs as much as a hundred thousand one-item arrays. A copy made by `map`, `slice` or `filter` is new space, O(n) for one call, even when it looks like a single line; a loop that reads the array in place is O(1) extra space. [Session 9.2](/path/9-2-trial-of-blades/) measures both.
