title: Data Structures

Lists, hashing, trees and graphs as one progression. Each structure gets the Holt lesson that builds it from scratch, and where a prep sheet exists it follows with the interview problems that structure unlocks: linked-list pointer games, stack and queue idioms, hash-map counting, tree traversals, heaps, tries and graph search.

## Lists
ArrayList and LinkedList built by hand, then the pointer patterns and the stack/queue idioms interviewers reach for.

## Hashing
Hash maps as the universal counting tool, and Bloom filters for "probably seen it".

## Trees
Binary search trees, AVL rotations, traversals, heaps, tries and the problem sheets for each.

## Graphs
Graph representations, BFS/DFS, topological sort, Dijkstra and union-find.
