title: Design Patterns

All twenty-three Gang of Four patterns as runnable JavaScript reference cards. Each card states the intent, the problem it solves, the sentence to say, where you have already used it in Node or React, and the pattern it is confused with. Every file ends with an `ok:` line so you know the examples really run.

## Creational
How objects get made: factories, builders, prototypes and the one-instance rule.

## Structural
How objects are composed: wrappers, bridges, trees, proxies and shared state.

## Behavioral
How objects talk and divide responsibility: observers, strategies, commands, iterators and state machines.
