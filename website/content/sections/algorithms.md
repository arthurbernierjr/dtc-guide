Start with how to measure (Big O, space, trade-offs), then the sorts and searches everyone is asked to explain, then recursion and the twelve interview patterns written as runnable JavaScript with asserts. The Holt lessons teach the idea; the prep sheets turn each idea into the problem shapes that show up in a 45-minute screen. Read the lesson, run the sheet, say the "SAY" line out loud.

## Analysis
How to reason about cost before you write a line, plus the two cheat-sheets you will keep open during practice.

## Sorting
Six classic sorts explained from first principles, then the comparators and partition tricks you actually use.

## Searching
Binary search as a lesson, then the eleven shapes it hides inside (bounds, rotated arrays, search on the answer).

## Recursion
Recursion itself, then the two patterns built on it: backtracking and dynamic programming.

## Patterns
The reference sheets: arrays, strings, two pointers, sliding window, intervals, grids and bits.

## Graph algorithms
Breadth-first pathfinding on a grid, from the Holt course.

## Naive vs Optimal
Four problems solved twice with the same tests, so the pattern names stop being abstract.
