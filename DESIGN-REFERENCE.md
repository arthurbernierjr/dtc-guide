# It's Deeper Than Code — The Guide: Design Reference

Nov 2, 2026 · @Arthur Bernier

A 226-page learning site (algorithms, data structures, practice, nine languages, system design, patterns, security, mindset) that has to read like one of the gift sites, not like documentation. Three frames: **Desktop 1440×900**, **Tablet 834px**, **Mobile 390px**. Same template order on all three; per-viewport differences are called out inside each section. Tokens live at the top of `website/public/styles.css`; this file is the source of truth they are copied from. Section numbers here (§0 … §14) are the ones `TEST-INSTRUCTIONS.md` and the visual QA checklist refer to.

## Global style

The look is ELEVEN28's dark luxury base wearing the It's Deeper Than Code sticker: near-black rooms, warm off-white type, and the three sticker colours used with discipline. **Green acts** (links, active states, CTAs, "fast" complexity), **red punctuates** (the signature, `CODE` in the wordmark, "slow" complexity, don't-do-this callouts), **yellow highlights** (eyebrow rules, `SAY` terms, search matches, "middle" complexity). The black sticker outline becomes the shadow language: cards lift with a hard offset shadow, like a sticker peeling off the page. Dark only. Nothing from Brian Holt's site is reused visually.

- **Background:** `--bg #08080A` everywhere. Section bands `--surface #111114`, cards `--card #16161A`, hover `--hover #1C1C22`, code panels `--code #0D0D10`. Hairline borders `--border rgba(255,255,255,.06)`; emphasised hairline `--border-2 rgba(255,255,255,.12)`.
- **Brand accents (sampled from the sticker / thumbnail):** `--green #00A868` (rgb `0 168 104`), `--green-deep #007838` (the thumbnail disc), `--green-light #2FD48F` (gradient ends, hover text); `--red #F03038` (rgb `240 48 56`), `--red-deep #B8161F`; `--yellow #E8D800` (rgb `232 216 0`), `--yellow-soft #F5EC5A`. Each has an `-rgb` triple for `rgb(var(--green-rgb) / .x)` glows, scrims and borders.
- **Text:** body `--text #EAE6E1`, headings `--heading #F5F2EE`, ledes `--soft #C6BFC4`, labels `--muted #8A8A94`, hairline text `--faint #55555E`. On green fills (pills, disc) text is `--ink #07110C`. Never pure `#FFFFFF`.
- **Complexity badge scale (used on every chip that shows a Big-O):** `O(1)`, `O(log n)` → green text on `rgb(0 168 104 / .12)`; `O(n)`, `O(n + m)`, `O(V + E)` → text `--text` on `rgb(255 255 255 / .06)`; `O(n log n)` → yellow on `rgb(232 216 0 / .12)`; `O(n²)` and worse (`O(2ⁿ)`, `O(n!)`) → red on `rgb(240 48 56 / .12)`. Badge: JetBrains Mono 12px, `padding 3px 9px`, `border-radius 6px`, 1px border of the same colour at 30%.
- **Type:** Display **Clash Display** 700/600/500 (self-hosted woff2 from `_801`) for the wordmark, H1, H2 and section numbers. Body **DM Sans** 17px/1.7 (variable TTF + italic woff2 from `_801`), 16px on mobile. Eyebrows, chips, breadcrumbs, code and every number that is "data" use **JetBrains Mono** (TTF from `_802`) 13px, `+.18em` tracking, uppercase. Code blocks: JetBrains Mono 14px/1.65 (13px mobile), no ligatures.
- **Wordmark (HTML, never an image):** four stacked lines, Clash 700, `line-height .92`, `letter-spacing -.02em`: `IT'S` (yellow, 38% of the main size, tracked `+.08em`), `DEEPER` (green), `THAN` (yellow, 38%), `CODE` (red, rotated −2°, like the sticker). Main size `clamp(72px, 11vw, 160px)`. Each coloured line carries a 2px `--bg` text-stroke and a `6px 6px 0 rgb(0 0 0 / .55)` text-shadow so it reads as a sticker on dark. The small `IT'S` / `THAN` lines are right-aligned to `DEEPER` / left-aligned under `DEEPER` respectively (as in the logo).
- **Signature:** *— the guide, by Big Poppa Code* — DM Sans italic 300, 18px, `--red`, preceded by a 48px red dash, tucked under the wordmark's right edge on desktop, centred below it ≤1100.
- **Eyebrows:** JetBrains Mono 11px, `letter-spacing .26em`, uppercase, `--yellow`, with a 48px 1px yellow rule to the left; numbered `01 / ALGORITHMS` … `08 / MINDSET` on the home page and `0N / {Section}` on landings.
- **Shapes:** radii 6 (chips, badges, inline code) / 14 (cards, code panels) / 22 (hero disc, feature cards) px; 999px pills. **Sticker shadow:** at rest cards have `box-shadow: 0 0 0 1px var(--border)`; on hover `translate(-2px, -2px)` plus `box-shadow: 4px 4px 0 0 #000, 0 0 0 1px rgb(0 168 104 / .35)`. The same move with `--red` on the "don't" callout and `--yellow` on the `SAY` chips.
- **Texture:** 3% film grain, fixed layer, `z-index 95`, the exact SVG `feTurbulence` from `_801` (`baseFrequency .9`, 180px tile). The thumbnail's white dot-grid as `radial-gradient(rgb(255 255 255 / .09) 1px, transparent 1.5px)` on a `22px` grid, masked with a radial fade, placed top-right of the hero and bottom-left of every landing header and quote break, never behind body text. A green radial lift (`rgb(0 120 56 / .35)` → transparent, 640px) behind the hero disc.
- **Motion:** `.reveal` → `opacity 0 / translateY(24px)` → in view over 700ms, stagger `(i % 6) × 60ms`, home page and landings only; doc pages do not reveal (reading first). Hero disc floats 7s/6px. Marquee 32s. Nav gains its blur after 40px of scroll. Sidebar/TOC active states transition 150ms. Everything honours `prefers-reduced-motion` (reveals shown, loops stopped, float off, scroll-spy still updates). No custom cursor anywhere on doc pages; a 6px green dot cursor with a 36px lagging ring on the home page only, desktop only.
- **Fixed UI (all viewports):** ⌘K search pill in the nav (right); 2px reading-progress rule in `--green` directly under the nav on doc pages; 48px round back-to-top button bottom-right (`--card`, green arrow) after 600px of scroll. **Mobile (≤767) only:** a 56px bottom bar with three equal buttons `Menu · Search · On this page` (JetBrains Mono 11px, icons from the inline sprite), `--surface` with the top hairline and a 24px blur backdrop.
- **Container:** `min(1240px, calc(100% - 96px))` on the home page and landings (`calc(100% - 48px)` ≤834, `calc(100% - 32px)` ≤480). Doc pages use the full-width 3-column grid in §5 instead.
- **Section rhythm (home + landings):** vertical padding 128px desktop / 96px tablet / 64px mobile. `.section-head` is left-aligned: eyebrow → H2 (Clash 600, `clamp(40px, 5.2vw, 72px)`, `line-height 1`) → one-line lede in DM Sans 18px `--soft`.
- **Icons:** one inline `<svg hidden>` sprite (search, menu, close, arrow-up, arrow-right, arrow-left, external, copy, check, play, chevron, list, book, code, globe, shield, layers, brain, hash). Single-weight 1.5px strokes, `currentColor`. No icon libraries, no emoji in UI chrome.

## 7. Doc components (every one appears in `styles.css` under the same name)

- **At-a-glance card** (`.glance`): `--card`, 14px radius, 20px padding, yellow eyebrow `AT A GLANCE`. Rows per header key, each a 2-column grid `72px 1fr`: key in mono 11px `--muted` uppercase (`WHAT`, `TELL`, `SAY`, `BIG-O`, `NOTE`, `HAPPENS`, `SPOT`, `FIX`, `INTENT`, `PARTICIPANTS`, `SEEN IN`, …, verbatim from the source), value in DM Sans 14px `--text`. `SAY` values split on `·` / `;` into **yellow chips** (`rgb(232 216 0 / .12)` fill, yellow text, 6px radius, mono 12px). `BIG-O` values are parsed into **complexity badges** (scale above), one per `O(...)` found, keeping the surrounding text in `--muted`. For T-LESSON pages that have a cheatsheet row, the card shows `BEST / AVERAGE / WORST / SPACE / STABLE` badges from that row. Desktop: right rail. Tablet/mobile: inline under the lede.
- **Section block** (`.block`, T-PREP): a `--surface` panel, 14px radius, 0 padding, hairline. Header 56px: the block number in Clash 600 20px `--green` (`01`), the title verbatim in DM Sans 16px 600 `--heading`, the separator-line idea text (if any) in `--soft` 14px, and the complexity badge(s) parsed from that line right-aligned. Body: the **code panel**. Footer: a `Verified by N asserts` disclosure (mono 12px, chevron) that reveals the assert lines as a read-only code panel.
- **Code panel** (`.code`): `--code` background, 14px radius (0 on mobile edges), hairline. **Header bar** 40px: language label left (mono 11px `--muted`: `JS`, `PY`, `RB`, `GO`, `JAVA`, `C#`, `PHP`, `RS`, `DART`, `TS`, `HTML`, `CSS`, `SH`, `JSON`, `SQL`), optional **tabs** in the centre (mono 12px, 32px tall, active = `--text` with a 2px green underline; inactive `--muted`), **Copy** icon button right (shows `check` + `Copied` for 1.2s) and, on runnable panels, a **Run** pill (green, 28px, `Run ▸`). Body: Shiki-highlighted `<pre>` with the custom `dtc-dark` theme (strings `--yellow-soft`, keywords `--green-light`, functions `#EAE6E1`, comments `--faint`, numbers `#F5A8AC`, types `#9FE3C8`), line numbers in a `--faint` gutter (hidden ≤480), `tab-size 2`, horizontal scroll, max-height 560px with a `Expand` row when clipped. **Output drawer** under runnable panels: slides open to 120–240px, mono 13px, each `ok:` line prefixed by a green `✓`, errors in red with the stack folded; a `Clear` text button.
- **Run worker:** executes the raw `_scratchbox` file in a Web Worker with a shim for `node:assert/strict` / `assert` (`strictEqual`, `deepStrictEqual`, `ok`, `throws`, `equal`, `notStrictEqual`, `deepEqual`, `rejects`, `match`) and `console.log`/`error` piped to the drawer. Files that `require` anything else are not run: the button becomes **Copy `node` command** and a one-line reason appears under it (`uses node:crypto`).
- **Try-it-first gate** (`.gate`, T-EXERCISE): sits between Examples and the tabs. A `--surface` panel with a 1px dashed green border, 32px padding, the title **Try it first** (Clash 600 22px), one sentence (`Write it in your editor, run the tests, then open the solution.`), a primary pill **Show the solution** and a ghost text button **I have tried it, skip**. Revealing animates the tab panel in (opacity + 12px). State per URL in `localStorage` (`dtc:gate:<url>`); a tiny `Hide again` link appears in the tab header once revealed.
- **Exercise header** (T-EXERCISE): the **Directions** as a quote-style block (`--surface`, 4px green left rule, DM Sans 17px, verbatim lines), then **Examples** as a code panel (`JS` label, the example lines), then the gate, then the code panel with tabs `Solution · Alternate 1 … · Tests · Helper`. Chips row under the H1: `N TESTS` (mono), the topic chip (group), `GPL-3.0` (red outline chip).
- **Language switcher** (`.lang-switch`): a sticky (`top: 72px`, under the nav; `top: 120px` on tablet under the toolbar) horizontal scroller of 9 pills (`JavaScript · Python · Ruby · Go · Java · C# · PHP · Rust · Dart`), 32px tall, mono 12px, the current language green-filled (`--ink` text), the others `--card` with hairline; each pill links to the same sub-page in that language (falls back to the language index when the sub-page does not exist, e.g. JavaScript has no `routing`). Frontend pages show `React · Vue · Angular · Svelte · Cheatsheet` instead. A thin `←  →` fade at the edges when it overflows (mobile).
- **Paired blocks** (T-LANG): where the source has "How we did it in JavaScript" / "How we do it in X" pairs, render two code panels side by side on desktop (`JS` left, the language right) with a shared caption; stacked on tablet/mobile with the caption once.
- **Callouts** (`.callout`): `--surface`, 14px radius, 20px padding, 4px left rule. ## Don'ts

- No pure `#fff`; no blue, purple or orange anywhere (the complexity scale is green / yellow / red only; links are green).
- No light mode, no theme toggle.
- No external requests at runtime: no CDN scripts, no analytics, no web-font calls, no iframes. CodeSandbox and docs links are plain outbound anchors.
- No Brian Holt photos, Frontend Masters logo, third-party course-provider logos, Repl.it badges, Heroku buttons or dead hosted (imgur / Dropbox / former LMS) images.
- No emoji in UI chrome (the `✦` and `✓` glyphs are typographic, drawn from the fonts). No icon libraries.
- No invented numbers: every count on the site is computed from the registry at build.
